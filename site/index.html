Loadouts

Your loadout, one flick away.

Like a game loadout, but for files. Save any tool's settings as a loadout from its window, or chain steps in a small text file. Hold Control while dragging and they're on the wheel.

One decode and one encode per chain, so steps never compress twice.
Run them on watch folders: new files are handled as they arrive.
Passwords never go into a loadout.
web-ready-image.toml
name = "Web-ready image"
description = "Longest side 2048 px, WebP, no metadata"

[[steps]]
op = "resize"
max = 2048

[[steps]]
op = "convert"
to = "webp"
quality = 80

[[steps]]
op = "strip_metadata"
Terminal
# the same engine as the wheel
$ radlet convert *.heic --to jpg
$ radlet compress photo.jpg --target 2MB
$ radlet translate notes.md --to fr
$ radlet loadout "Web-ready image" *.png

# let Claude and other AI apps use it, locally
$ claude mcp add radlet -- radlet mcp
Command line & AI agents

Same engine, everywhere you work.

Almost every tool on the wheel is a radlet command, ready for scripts and Shortcuts. radlet mcp lets Claude and other AI apps convert, compress and clean your files on your own Mac.

JSON output for scripts with --json.
Password tools are never offered to agents.
Why “Radlet”
A little radial. The Latin radius was the spoke of a wheel, and in German and Dutch, Rad simply means wheel.
